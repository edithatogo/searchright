# Pilot deployment protocol

Pilots progress from fixture-only local use to institution self-hosting and only
then to a separately threat-modelled remote single-tenant deployment. Each pilot
has named users, data classification, supported sources, success measures,
incident contacts, rollback criteria and an exit decision.

No pilot may use autonomous final exclusions. Restricted full text, licensed
provider credentials and personal data remain deployment-controlled. Findings
and failures are preserved even when a pilot is stopped.
