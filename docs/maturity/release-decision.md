# Version 1.0 release decision

Current decision: **not ready**.

A final release decision is made only after every domain in
`conductor/maturity-dossier.json` has current evidence, no critical blocker, a
named accountable reviewer and a rollback/support plan. The decision must cite
the exact Git commit, release candidate, SBOM, attestations, downstream canaries,
pilot exits, external evaluation and registry evidence.

Source implementation, closed GitHub issues or a populated Project cannot make
the decision ready. A signed tag is created only after the decision receipt is
approved; publication and registry submissions remain separate approval-gated
actions.
