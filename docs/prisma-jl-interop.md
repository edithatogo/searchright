# PRISMA.jl interoperability boundary

Searchright compared its validated `org.searchright.prisma-flow.v1` fixture with
the flow-template rows at the pinned `edithatogo/PRISMA.jl` revision
`95d5aa46c6cda6fb2d014391209d666349b577dc`. The deterministic fixture maps the
shared count projection and records model differences rather than hiding them.

Searchright is the canonical arithmetic authority for Searchright flows.
PRISMA.jl remains an optional presentation comparator; it is not canonical
screening state, review authority, or evidence that Searchright is equivalent to
the Julia package. In particular, Searchright v1 aggregates some other-method
channels and does not separately model previous-versus-new included studies.

The comparison fixture is
`integration/fixtures/prisma-jl/flow-parity-v1.json`. Its labels are attributed
to the pinned MIT-licensed PRISMA.jl source. No remote companion change is
required or authorised by this decision.
