# Safety case

## Top-level claim

Searchright can assist systematic-search work without silently expanding agent
authority, provider access, data retention or public evidence claims.

## Arguments and current evidence

| Argument | Principal controls | Current evidence | Open gate |
| --- | --- | --- | --- |
| Retrieved content cannot directly control tools | Untrusted-content policy; content/data separation | Source contracts and hazard log | Hostile-content agent tests |
| Network and external effects are bounded | Default-deny capability matrix; host/budget policy | Source checks | Compiler/adversarial/runtime evidence |
| Screening remains human-governed | Authority contract; no autonomous final exclusion | Source invariants | Human calibration and usability pilot |
| Extraction cannot silently canonicalise | CiteWeft one-way adapter; canonical write false | Schema and static adapter check | Compiled golden fixtures |
| Audit and provenance are inspectable | Hash-linked events; receipts; evidence ladder | Source checks | Crash/tamper execution tests |
| Supply chain is reviewable | Pins, SBOM, attestations and security workflows | Workflow/source checks | Executed clean-room and release CI |
| Integration changes are reversible | Passports, exact pins, drift detection, rollback | Static passport checker | Consumer-driven downstream runs |

## Defeaters

A clean static harness is not a proof of runtime safety. A successful fixture is
not proof of live-provider completeness. Human approval is not valid when the
reviewer cannot inspect the underlying evidence or when policy/criteria changed
silently. Any such condition blocks the corresponding claim.
