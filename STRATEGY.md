# Strategy

## Strategic thesis

The defensible advantage is not the number of database integrations. It is a
portable evidence-search contract plus an audit-preserving runtime that every
interface and downstream repository reuses.

## Strategic pillars

1. **Contract first:** review intent, query semantics, provenance, screening and
   reports are versioned before adapters.
2. **Shared kernel:** extract provider runtime from Sourceright and prohibit
   downstream reinvention.
3. **Deterministic by default:** fixtures, replay, canonical JSON and hash chains
   precede live APIs and probabilistic agents.
4. **Standards as executable checks:** PRISMA-S, PRISMA 2020/ScR/LSR and PRESS are
   represented as traceable requirement ledgers, not badges.
5. **Human-governed agents:** agents may plan, translate, rank and explain; policy
   controls protocol amendments and final exclusions.
6. **Open-core interoperability:** CLI, MCP, Rust API, JSON/YAML, WIT, RIS/CSL and
   review-system adapters share one model.
7. **Evidence before claims:** support and registry status progress from
   contracted → fixture-backed → live-proven → publicly accepted.

## Positioning

Searchright is infrastructure for evidence retrieval and selection. It should
integrate with tools such as Zotero, EndNote, Rayyan, Covidence, ASReview and
review-specific pipelines rather than attempting to replace every user interface.

## Near-term wedge

The MVP solves a high-value, bounded sequence:

- represent PICO/PCC and eligibility criteria;
- compile one canonical query into PubMed and Europe PMC syntax;
- import RIS/CSL/JSON records;
- deduplicate with reviewable evidence;
- record dual screening decisions;
- produce PRISMA-S search appendices and PRISMA flow arithmetic;
- expose the same operations through CLI and MCP.

## Non-goals before 1.0

- autonomous final inclusion/exclusion without review policy;
- scraping licensed databases;
- making legal or clinical truth claims about retrieved evidence;
- hosted multi-tenant SaaS;
- opaque end-to-end “one click systematic review” claims.
