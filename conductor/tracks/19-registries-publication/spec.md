# 19: Registries and scholarly publication

## Objective

Submit validated release metadata to relevant registries and prepare a software paper.

## Scope

- Validate server.json against official MCP Registry schema
- Publish Glama and Smithery/MCPB metadata
- Publish crates.io and GitHub release artefacts
- Submit official MCP Registry after package availability
- Record public acceptance URLs/version/dates
- Prepare JOSS/Zenodo/OSF artefacts and citation metadata

## Requirements owned

See `conductor/requirements.md` rows whose Track owner includes `19`.

## Acceptance contract

- All named tasks have implementation, deterministic tests, documentation and a
  machine-readable verification receipt or an explicit external blocker.
- Public claims remain at the achieved evidence level.
- Security, privacy, migration and rollback impact are reviewed.
- CLI/MCP/facade parity is preserved where the track changes a public operation.
