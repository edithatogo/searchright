## Canonical data and product boundary

Searchright owns systematic multi-source search and corpus construction. Sourceright owns canonical reference reconciliation; CiteWeft owns extraction. ASReview owns screening. pybibx, bibliometrix and VOSviewer own their analyses.

`references.csl.json` is the sole canonical bibliography, validated against a pinned upstream CSL-JSON schema. Stable string CSL IDs are the local integration keys; DOI is neither mandatory nor a universal publication-version identity. Map numeric source IDs explicitly. Do not create another canonical bibliography in CSV, RIS, BibTeX, Parquet, an ASReview project or an OpenAlex-shaped file.

Keep structured reference edges, authorship-affiliation relations, field-level observations, rights, citation counts, identity crosswalks and search lineage in versioned sidecars keyed by CSL ID and corpus revision. Preserve native responses as immutable source evidence. CSL's `references` string is not a reference graph; `custom` is not permission to hide unversioned execution state inside references. Derived exports carry complete field-loss and identity reports. Return events propose canonical changes; they never silently overwrite reviewed references.

## Reuse before custom implementation

- Git owns code and configuration. DVC is an optional file-stage pipeline/cache profile only after a measured benefit over the existing Rust/CI workflow; do not make it a core prerequisite or build another scheduler.
- The existing Rust core owns acquisition, explicit authority and crash recovery. Retain maintained HTTP/TLS/XML/CSV dependencies and qualify exact versions.
- Qualify OxiDD against the existing simple Boolean baseline for identical semantics, MSRV, maintenance and actual cost before adoption; unsupported domain semantics return Unknown.
- Qualify Salsa against existing targeted invalidation; adopt only when it measurably simplifies implementation or improves recomputation. It does not own acquisition durability.
- Reuse maintained JSON Schema validators, canonical-JSON tooling where needed, Workflow Run RO-Crate tools and an independently maintained conformance validator.
- Optional profiles: TLSNotary session authenticity, OpenLineage events, institutional Snakemake execution, local-model/adversarial search audits, signing, GitHub/Hugging Face/archival deposits. None is a core-release prerequisite. No bespoke crypto.
- Qualify licence, maintenance, platform/API compatibility, failure behaviour and rollback before replacing code. Remove old implementations only after parity tests.

The default is the existing Rust CLI plus reproducible CI. DVC and Snakemake are optional alternative execution profiles, never simultaneous authorities; adopt when justified by consumer workflows. Restricted inputs cannot use an indiscriminately shared cache. Optional telemetry is disabled.

## Independent consumers

ASReview's documented dataset/subcommand extension interfaces are appropriate; do not add classifier or stopping extensions. Implement the portable file handoff before the thin plugin. Importing a plugin must not execute searches or retrieve credentials. Pin and test the actual consumer version.

pybibx is a separate adapter with no ASReview dependency. Its inspected upstream README documents source-specific imports, not a general CSL-JSON importer. Qualify a public neutral input route or genuine permitted native snapshots with canonical crosswalks. Do not impersonate Scopus/WoS/OpenAlex with fabricated exports or modify private DataFrame internals. A profile that cannot represent a corrected canonical corpus is unsupported, not silently inconsistent. Missing references/affiliations are not zero; source citation counts must not be added together.

## Dynamic versioning and cache correctness

Separate logical corpus ID, immutable content revision, observation ID, run ID, attempt ID, protocol version, schema version, consumer profile and release version. Hash an inventory of bibliography/sidecar digests that excludes its own revision field. Mutable aliases may resolve a revision but cannot be an evidence dependency.

Bind deterministic reuse to input/sidecar digests, operation, code and dependency locks, environment, parameters, vocabularies, policy/access partition and relevant model/prompt/seed/runtime. Preserve raw-byte and semantic hashes as different types. A fresh live acquisition is a new observation even if its response bytes match a previous run. A cached query does not establish a fresh search of a changing index.

Every change invalidates actual dependent artifacts: new records, metadata correction, identity merge/split, protocol amendment, vocabulary change, source withdrawal or consumer profile. Publication numbers, tables and figures bind to exact protocol, corpus, run and result revisions; rerunning an analysis invalidates stale manuscript objects. Failures remain explicit and cannot promote incomplete outputs.

## Research portfolio and claim boundaries

R1 translation fidelity; R2 reconciliation/export loss; R3 bibliometric corpus sensitivity; R4 upstream search with ASReview fixed; R5 temporal reliability; R6 independent reconstruction; R7 published-strategy ambiguity and uncertainty. Draft protocols are not registrations. Candidate journal audiences are not verified submission rules. No study result, superiority or publication acceptance is claimed.

The SEARCH-REPLAY protocol and publication contract are drafted separately. The meaningful extension of prior reporting audits is a bounded, independently justified reconstruction multiverse and its record-level consequences, not another claim that reporting is often incomplete. Preserve count-based historical comparisons as secondary endpoints: identical counts need not identify identical records.

A capability-specific beyond-frontier claim requires working technical demonstration, a prespecified meaningful methodological advantage over strong comparators, independent reconstruction, and a refreshed prior-art comparison. Ordinary local releases do not wait for papers or registry acceptance. Checksums, compilation and architecture do not establish scientific superiority.
