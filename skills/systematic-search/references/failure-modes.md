# Failure modes and countermeasures

- **Database/platform conflation:** preserve both fields and exact syntax.
- **False translation equivalence:** surface lossy warnings; require source review.
- **Outcome overconstraint:** test known-item recall and justify concept selection.
- **Unavailable source substitution:** report omission; never relabel an open API.
- **Pagination truncation:** receipt warning plus explicit page/record budgets.
- **Duplicate over-merging:** retain cluster evidence and require fuzzy review.
- **Report/study conflation:** link multiple reports to one study explicitly.
- **Agent false-negative exclusion:** advisory-only default and calibration gates.
- **Protocol drift:** immutable versions and amendments linked to runs/decisions.
- **PRISMA backfilling:** derive counts from events, block inconsistent arithmetic.
- **Credential leakage:** redact URLs/headers/errors and prohibit secrets in events.
- **Prompt injection in abstracts/full text:** treat content as data, not instructions.
- **Registry overclaim:** prepared/submitted/accepted states require separate evidence.
