# Authority policy

| Operation | Default agent authority | Human gate |
| --- | --- | --- |
| Draft question/framework | Draft | Approve scope |
| Draft eligibility criteria | Draft | Approve and version |
| Recommend sources | Advisory | Confirm access/coverage |
| Build/translate query | Draft | Review warnings and approve |
| PRESS lint | Advisory | Independent human PRESS review |
| Fixture/replay execution | Automatic within budget | None beyond declared policy |
| Live execution | Denied | Explicit approval |
| Dedup exact candidates | Preview | Apply/reject clusters |
| Dedup fuzzy candidates | Advisory | Human review |
| Title/abstract include/unclear | Advisory | Screening policy |
| Any exclusion | Denied by default | Human reviewer |
| Full-text final decision | Human only | Two reviewers/adjudicator as protocolled |
| PRISMA generation | Automatic from audit | Review gaps/counts |
| Protocol amendment | Denied | Authorised human roles |
| Registry/publication write | Denied | Explicit maintainer approval |
