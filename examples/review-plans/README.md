# Review-plan examples

This directory contains bounded research-plan examples for Searchright.

Examples are not runtime-schema conformance evidence, completed searches, methodological certification or publication-ready reviews. Each example must state its evidence level, human-authority boundaries, required receipts and prohibited claims.

## Scope of Agency example

`scope-of-agency-scoping-review.yaml` describes a systematic scoping-review handoff spanning clinical credentialing, scope of practice, agent lifecycle governance, robotic actuation and institutional legitimacy. It deliberately leaves protocol amendments, final inclusion and exclusion, legal and clinical interpretation, novelty adjudication and readiness claims under human authority.

Before promotion beyond an example, the plan requires:

- validation against the current Searchright contract or a documented adapter;
- source-specific query translations and translation-loss receipts;
- a seed-set sensitivity check;
- run receipts and amendment history;
- deduplication and record-study linkage;
- dual-phase screening evidence;
- PRISMA-ScR and PRISMA-S compatible outputs.

The example does not establish comprehensive retrieval or residual novelty.
