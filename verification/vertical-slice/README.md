# Contract reference vertical slice

This rights-clear synthetic fixture proves that the checked-in contracts and
network-free reference controls can be assembled into one coherent review path:
plan, native strategy, source receipts, records, duplicate clusters, human
screening, PRISMA arithmetic and a deterministic review bundle.

It is **not** an alternative production implementation of the Rust engine. It
does not establish Rust compilation, provider correctness, search recall,
screening validity, live interoperability or methodological adequacy.
