# Single-owner governance

Searchright is a single accountable human/developer project. Review gates use isolated panels of agents, not additional human reviewers. Panel members perform sealed first passes, preserve dissent, and provide advisory findings. Only the accountable owner adjudicates findings and authorises promotion.

Companion-repository tracks are portable. The propagation agent discovers exact local clones, rejects dirty or divergent state, fast-forwards synchronised clones, clones missing repositories, imports tracks idempotently on isolated branches, executes all available target-native verification, and records pending native commands when the required toolchain is unavailable. Pending confirmation blocks release promotion; authored or interim test failure blocks commit.
